RANGREZ website (HTML, CSS, JavaScript)

HOW TO RUN
1. Extract rangrez_website.zip.
2. Open the rangrez_website folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension in VS Code.
4. Edit index.html, style.css, and script.js as needed.

IMPORTANT BEFORE LAUNCH
- Replace hello@rangrez.example in index.html and script.js with the official email address.
- Add official Instagram and WhatsApp links/numbers when available.
- Event dates and venues are intentionally marked as to be announced; confirm details before publishing.
- The contact form currently prepares an email via mailto. A backend or form service is required to receive enquiries directly.
- Event/gallery photos use remote Unsplash images and need an internet connection. Replace them with approved RANGREZ assets before launch.
- This is a front-end static website; no ticket payments or database are included.
